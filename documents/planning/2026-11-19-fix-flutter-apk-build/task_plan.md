## Decisions Made
| Decision | Rationale |
|----------|-----------|
| Let the Novel Sound build script prefer an installed Rustup toolchain and verify Android target libraries. | The shell selected a MacPorts Rust compiler without Android std; this makes the normal Flutter build use installed targets and gives a targeted setup message otherwise. |
| Suppress only the exact GSS missing-class warnings generated by R8. | SMBJ's Android integration configures NTLM authentication; its optional Java SE GSS references are not available on Android. |
| Align path-package plugin constraints and remove root Workmanager overrides. | Root and nested dependency resolution must select mutually compatible plugin interfaces. |
