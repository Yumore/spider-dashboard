# 移动端 UI 对齐设计

更新日期：2026-11-13

## 目标与范围

参考 `/Users/nathaniel/workspace/AndroidStudio/SpiderMan/documents/designs` 中的主 TAB、我的和偏好设置实机图，调整 Flutter 工程的移动端主导航、全局应用栏/主题和“我的”入口。各模块继续使用现有页面、数据和交互，不将参考截图或静态内容作为实现。

参考重点：`01-anime.png` 至 `06-mine.png`、`60-current-entry.png`、`61-preferences-hub.png`、`62-reader-preferences-entry.png`。

## 设计令牌

- **强调色：**沿用 `AppTheme.themeColors` 的七种可选颜色（胖次蓝、姨妈红、咸蛋黄、早苗绿、少女粉、基佬紫、朴素灰）。页面强调色、当前导航项、应用栏和状态栏前景从当前主题生成；不把参考图的蓝色写死。
- **浅色表面：**页面用近白底，卡片/导航栏用白色，正文和图标从主题 `ColorScheme` 取色。
- **深色表面：**页面、卡片和导航栏由深色 `ColorScheme` 提供，保持相同的强调色选择。
- **对比度：**应用栏文字和系统状态栏图标根据强调色的前景色选择，避免黄色主题出现白字低对比。
- **分隔线：**使用主题描边色；“我的”菜单分隔线使用低透明度强调色。
- **文字：**沿用 Flutter 平台默认中文无衬线字体；屏幕标题 22sp 左右，正文 16sp，辅助文字 13sp，底部标签 12–13sp。

## 布局方案

```text
┌ 状态栏 + 主题色应用栏（居中标题 / 搜索动作） ┐
│ 当前模块：保留原有业务页、数据和内部标签      │
│                                                  │
├ 动漫 ─ 漫画 ─ 直播 ─ 短剧 ─ 书架 ─ 我的 ────┤
```

- 手机宽度下固定六项底部导航，图标和标签都显示；选中态使用当前强调色，其他项使用主题次级文字色。
- 宽屏改用左侧导航轨道，避免把六个标签挤在横向空间中。
- 动漫、漫画、短剧内容保持图片优先的现有页面；直播、书架保留其订阅与阅读业务，不以空卡片代替。
- “我的”采用长列表分组：账号、个人内容、偏好/主题、全部内容模块；行内图标、标题和尾部箭头对齐。现有七色主题及浅/深/跟随系统选项继续可用。

## 原则

1. 主题色是用户选择，不是单一品牌色；任何 UI 改动都不能减少或重置现有颜色主题。
2. 主框架与参考图统一，模块内部保留自己的业务信息层级。
3. 不新增空操作、占位入口或重复的业务实现。
4. 使用安全区和响应式布局，不按截图像素硬编码手机尺寸。
