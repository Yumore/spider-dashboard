# 果幕 v1.4.3 更新说明

## 问题修复

- 修复 iOS 灵动岛 Widget 因 `CFBundleName` 为空，导致 Sideloadly 等工具签名安装失败的问题。
- 修复 Android Release 版本启动后停留在黑屏的问题。
- 修复通知图标可能在 Android 资源压缩阶段被移除的问题。

## 启动与稳定性

- Android 改为首帧优先启动：通知与后台任务不再阻塞首页显示。
- 通知、后台任务初始化增加超时和独立错误降级，单个可选插件失败不会影响进入应用。
- Android 启动画面改为品牌化深色背景与果幕图标，不再显示空白画面。
- iOS 构建流程新增主 App 与 Widget 扩展 `CFBundleName` 强制校验，避免同类问题再次进入 Release。

## 版本信息

- 版本：`1.4.3`
- 构建号：`8`
